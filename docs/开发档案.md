## 一、项目概览

Kisstr 是一个**书影音 · 优质网站收藏导航站**，由用户徐文进个人维护。全站纯静态、零构建，单文件自包含 HTML 架构（用户明确否决过"拆分网页"方案——拆分后加载更慢，维持现状）。

| 项 | 说明 |
|---|---|
| 语言 | 原生 HTML / CSS / JavaScript（无框架） |
| 部署 | Cloudflare Workers Static Assets（`wrangler.jsonc`，`assets.directory = "site"`） |
| 构建 | 无（零构建，开箱即用） |
| 统计 | Umami 轻量脚本（每个页面 head 内置） |
| 资源 | 本地静态资源，无 CDN 依赖 |
| 壁纸 | `site/wallpapers_webp/`（43 张 WebP） |
| 特性 | 13 种主题色 · 2 种布局（清晰/杂志）· 内置 lofi 电台 · 卡片 hover 金边 + 毛玻璃 |

## 三、技术规范与约定（硬约束）

1. **单文件自包含**：每个 HTML 内联完整 CSS/JS，可独立打开。不拆分（用户已定）。
2. **数据格式**：`const linksData = [...]` 为 **JS 对象字面量**（键可带引号可不带，非纯 JSON），用 `new Function` 求值校验。
3. **编码**：全部文件 **UTF-8 带 BOM**（写入必须用 `io.open(...,'w',encoding='utf-8-sig',newline='')` 保留 BOM）。
4. **条目结构**：`{ name, url, description }`（ai.html 历史条目可带 `_aiCompany/_aiScore/_aiTags` 扩展字段）。
5. **描述长度**：description **≤ 28 字**（用户 2026-10 定稿，四辑 vibe 共 1331 条已全部压缩合规）。
6. **索引收敛**：**索引分类只存在于 index.html**；所有支页不保留"索引"数据分类（2026-10-03 结构调整，48 个支页索引已全部移除）。
7. **渲染逻辑**：`linksData.forEach(...)`，含 `if (cat.name === '索引') return;` 的过滤逻辑；顶部"返回首页"按钮 `window.location.href='index.html'`。
8. **数据红线（用户强约束）**：禁止编造任何 URL/star 数/热度；每条必须可溯源（官网、GitHub API 或可访问一手页面）；无法核验的一律不收录，宁缺毋滥。
9. **链接原则**：优先官网和 GitHub，不用第三方下载站/镜像/论坛帖作主链接。
10. **配色**：支页有独立主题色（如 vibe 三辑青绿、四辑紫粉），不强制统一。

- 除 setProperty('--bg-image',bg) 外，额外直接写 h.style.backgroundImage=bg（内联样式变更强制浏览器立即重绘，绕开 var+合成层缓存）。
- 保留 .bg-layer 内联兜底（若未来有该元素）与 void h.offsetWidth 强制重排。

### 验证（真实浏览器）
- 点击 05_荷：0.4s 内 html computed backgroundImage = 05_荷（inline:true），面板开着背景已同步变化；2s 后保持 05_荷。
- 此前版本点击后 0.35s computed 也已变化，但屏幕渲染受合成层缓存影响，布局切换触发重绘才显示；内联方案消除该延迟。
